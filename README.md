## Project Summary & Problem
Shared households often run on informal agreements or guesswork, causing frequent disputes over money, unassigned chores, and depleted supplies. The Household Management System (HMS) is a centralized web platform designed to eliminate roommate disputes through shared expense tracking, peer-verified chores, and live inventory management.

## Target Users
* Housemates and roommates sharing living spaces and household responsibilities.

## Core Feature List
* **Expenses Module:** Expense logging, automated cost splitting, and debt settlement tracking.
* **Chores Module:** Chore creation, assignment workflows, completion submission, and peer verification.
* **Inventory Module:** Item stock logging, restock history, and low stock tracking.
